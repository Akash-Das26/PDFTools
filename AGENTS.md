# Agent instructions

Before ending any session that changes this project, append an entry to `REVIEW.md` at the repo root, using the session template in its Part 3. Updating `REVIEW.md` is a required last step of every session — do not mark any result "Verified" without citing the evidence in the entry.

Commit messages must not include generated-attribution footers — no "Co-Authored-By: Codebuff" (or any other agent) trailer, and no generated-with badges. Keep commit messages plain: subject + body only, written as if by a human contributor. (User rule, 2026-09-26.)
