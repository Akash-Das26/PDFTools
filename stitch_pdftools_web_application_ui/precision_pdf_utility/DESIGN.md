## Brand & Style

This design system synthesizes high-velocity utilitarian performance with refined software craft—bridging the direct, no-friction utility of browser toolkits with the disciplined restraint, crisp density, and micro-interactions characteristic of modern productivity suites (Linear, Notion, Raycast).

### Brand Personality & Emotional Archetype
- **Immediate & Frictionless:** Users arrive under task stress (deadline conversions, document signing, compression limits). The interface eliminates ambient noise, decorative filler, and multi-step orientation delays.
- **Engineered Reliability:** Documents contain sensitive, legally binding, or private content. The visual tone projects bank-grade deterministic security through crisp micro-borders, clean alignment, and zero visual ambiguity.
- **Craft & Density:** Every interface node reflects considered spatial tension. Tools feel sharp, tactile, and responsive rather than bloated or consumer-ad-heavy.

### Design Movement
- **Modern Minimalist Utility with Deep Surface Layering:** Combines razor-sharp architectural layout lines, structured dark/light neutral token pairing, subtle container elevations, and strategic red/blue semantic accents. Visual gravity is established via high-contrast typography, hairline boundaries, and restrained tactical color application.

## Colors

The palette establishes an immediate mental association between document actions and clear semantic categories. Red `#DC2626` stands as the primary signature anchor (honoring global PDF identity conventions and high-priority primary triggers). Secondary `#2563EB` bridges Office and external data bridges (Word, conversions, secondary workflows).

### Chromatic Usage Rules
- **Primary (`#DC2626`):** Reserved strictly for primary task progression ("Process PDF", "Download File", active tool identity glyph, upload confirmation targets). It is never applied indiscriminately to decorative cards or non-critical labels.
- **Secondary (`#2563EB`):** Dedicated to data pipeline bridges (Word/Office conversions, deep links, informational focus rings).
- **Success (`#16A34A`):** Exclusively signifies completed processing jobs, confirmed cryptographic checksums, verified document integrity, and completed downloads.
- **Warning (`#D97706`):** Highlights file size anomalies, quota constraints, password requirements, or irreversible rasterization warnings.
- **Neutrals & Dark/Light Theming:**
  - **Light Theme:** Pristine canvas (`#FFFFFF`) grounded with cool slate framing (`#F8FAFC`), structured hairline dividers (`#E2E8F0`), and commanding text hierarchy (`#0F172A`).
  - **Dark Theme:** Deep carbon background (`#0B0B0C`) layered over zinc tool chambers (`#18181B`), elevated popover panels (`#27272A`), and low-glare crisp type (`#F4F4F5`).

## Typography

The type system runs purely on `Inter` to deliver systematic typographic clarity across dense data matrices, parameter grids, and dynamic micro-copy (file sizes, cryptographic hashes, page quotas).

### Hierarchical Directives
- **Structural Contrast:** Weights are deliberately bimodal. Display headlines, primary buttons, and key state badges utilize `600` (SemiBold) or `700` (Bold) with tightened tracking (`-0.02em`) to provide commanding anchor weight. All explanatory text, helper descriptions, and input strings remain strictly at `400` (Regular) to ensure high scannability.
- **Metadata Clarity:** File sizes (e.g., `14.2 MB → 2.1 MB`), page counts, and keyboard commands (`⌘K`) leverage `label-sm` with slight positive tracking (`0.02em`) to guarantee legibility in compact badges and thumbnail corner ribbons.
- **Scale Compression:** Mobile viewport overrides (`headline-xl-mobile`, `headline-lg-mobile`) compress line heights to prevent multi-line headline wrap while preserving layout parity with desktop workspaces.

## Layout & Spacing

Layout geometry follows an 8px modular cadence designed around two distinct layout archetypes: the Discovery Grid and the 3-Step Execution Chamber.

### Spatial Structural Models
- **Landing Tool Grid (`max-w-7xl`):**
  - Desktop (≥1024px): 4-column responsive grid with `1.5rem` (`gutter`) spacing.
  - Tablet (640px–1023px): 2-column grid with `1rem` (`gutter-sm`) spacing.
  - Mobile (<640px): Single-column continuous stack with `1rem` vertical intervals.
- **Tool Workspace Chamber (`max-w-5xl`):**
  - **Desktop (≥1024px):** Fixed 60/40 asymmetric split layout. The left 60% viewport accommodates the primary interactive canvas (Dropzone, multi-page visual reordering canvas, or PDF canvas preview). The right 40% column locks the tool parameter panel and action triggers.
  - **Mobile (<1024px):** Reflows into a single vertically docked sequence: File Stage Indicator → Dynamic Interactive Canvas → Stacked Configuration Card → Floating Persistent Action Bar.
- **Spacing Rhythm:** Internal card paddings default strictly to `space-lg` (24px) on desktop viewpoints and scale smoothly down to `space-md` (16px) on mobile viewports.

## Elevation & Depth

This design system avoids loud skeuomorphic drop shadows, relying instead on high-precision tonal layering, crisp borders, and subtle diffuse boundary shadows.

### Elevation Hierarchy
- **Level 0 (Base Canvas):** Background substrate (`#FFFFFF` in light mode; `#0B0B0C` in dark mode). Completely flat.
- **Level 1 (Structural Cards & Dropzones):** Surfaces (`#F8FAFC` light; `#18181B` dark) separated from the canvas via a continuous 1px perimeter border (`#E2E8F0` light; `#27272A` dark).
- **Level 2 (Active Tool Modules & Hovered Nodes):**
  - Light mode: `0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.05)` accompanied by a border shift to `#CBD5E1`.
  - Dark mode: `0 1px 3px 0 rgba(0, 0, 0, 0.4)` accompanied by a border shift to `#3F3F46`.
- **Level 3 (Command Palettes, Popovers & Context Menus):** High-density floating elements (`#FFFFFF` light; `#18181B` dark) flanked by high-resolution multi-tier shadows:
  - Light mode: `0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.04)` with a 1px border (`#E2E8F0`).
  - Dark mode: `0 20px 25px -5px rgba(0, 0, 0, 0.6), 0 8px 10px -6px rgba(0, 0, 0, 0.5)` with a 1px border (`#27272A`).
- **Focus & Interaction Rings:** State selections receive an offset outer focus glow of `0 0 0 2px #FFFFFF, 0 0 0 4px #DC2626` in light mode, and `0 0 0 2px #0B0B0C, 0 0 0 4px #DC2626` in dark mode.

## Shapes

The interface expresses a clean, modern technical posture through a calibrated `rounded-xl` (12px) standard radius across all primary bounding containers.

### Shape Assignment Rules
- **Tool Cards & Dropzone Perimeters:** Locked to `rounded-xl` (0.75rem / 12px) to preserve visual balance across grid alignments.
- **Interactive Controls (Buttons, Form Inputs, Segmented Controls):** Built with `rounded-md` (0.375rem / 6px) to `rounded-lg` (0.5rem / 8px), maintaining an engineered, tactile feel distinct from the softer structural parent containers.
- **Page Thumbnail Elements:** Formed with `rounded-lg` (8px) borders, nesting cleanly inside the `rounded-xl` parent grid wrapper with uniform 8px internal gutters.
- **Badges, Status Pills & Metadata Tags:** Set to `rounded-full` (9999px) to immediately distinguish categorical attributes and file-extension indicators from actionable structural cards.

## Components

### Buttons & Interactive Triggers
- **Primary Action Button:** Background `#DC2626`, foreground `#FFFFFF`, font `label-md`, radius `rounded-lg`. Hover: `#B91C1C`. Active scale: 0.98. Focus: 2px offset ring.
- **Secondary Action Button:** Surface-matched background (`#FFFFFF` light / `#18181B` dark), 1px solid border (`#E2E8F0` / `#27272A`), text `#0F172A` / `#F4F4F5`. Hover: background `#F1F5F9` / `#27272A`.
- **Destructive Variant:** Text `#DC2626`, light tint background on hover (`#FEF2F2` / `rgba(220, 38, 38, 0.1)`).

### Tool Cards (Discovery Grid)
- Constructed with an outer `rounded-xl` shell, 1px hairline border, and 24px internal padding.
- Displays the assigned single Lucide icon framed within a 40x40px rounded container tinted with tool-specific thematic color tokens (e.g., `#FEF2F2` with `#DC2626` for core PDF operations, `#EFF6FF` with `#2563EB` for Word/Office tools).
- Title utilizes `headline-sm`, followed by a 2-line truncated description in `body-sm` (`#64748B` / `#A1A1AA`). Subtle border lightening on hover.

### Upload Dropzone (Step 1)
- Bounded by a dashed 2px border (`#CBD5E1` light / `#3F3F46` dark) with `rounded-xl` contouring.
- Drag-over state shifts background to faint brand tint (`#FEF2F2` light / `rgba(220, 38, 38, 0.05)` dark) and converts border to solid `#DC2626`.
- Includes an icon, prominent "Choose files" button, and secondary `label-sm` drop text indicating limits (e.g., "Up to 100MB each").

### Visual Page-Picker Thumbnail Grid
- Renders 6 columns on desktop down to 3 columns on mobile, encased in a container with a 1px border.
- Each page thumbnail is rendered inside a `rounded-lg` card featuring a persistent footer label indicating page number (`Page 1`, `Page 2`).
- Selection toggles: Checkbox positioned top-right with an active state of `#DC2626`. Selected cards project an active 2px border in `#DC2626`. Hover reveals micro-actions: rotate clockwise, rotate counter-clockwise, and delete.

### Form Controls & Parameter Inputs
- **Inputs & Dropdowns:** 1px border (`#E2E8F0` light / `#27272A` dark), background `#FFFFFF` / `#18181B`, radius `rounded-lg`, height 40px, padding `0.5rem 0.75rem`. Focus state features a sharp `#DC2626` border accompanied by a zero-blur micro ring.
- **Sliders (Compression / Watermark Opacity):** Rail `#E2E8F0` / `#27272A`, active fill `#DC2626`, circular thumb `#FFFFFF` encased in a 2px `#DC2626` border with subtle drag shadow.

### Progress & Processing Indicator (Step 2)
- Replaces configuration elements during execution. Features an animated indeterminate or determinate progress bar with `#DC2626` fill against a `#E2E8F0` / `#27272A` track, accompanied by a dynamic status label (`Compressing streams...`, `Encrypting 256-bit AES...`) and a secondary "Cancel" trigger.

### Result & Download Panel (Step 3)
- Anchored by an icon badge (`#16A34A` background tint).
- Metric Comparison block: Shows high-contrast before/after typography (e.g., `12.4 MB` strikethrough → `2.1 MB` bold `#16A34A` with a `-83%` badge).
- Primary CTA: Full-width download button in `#DC2626`.
- Secondary CTA: "Process another file" text link or secondary button to clear the state machine back to Step 1.
